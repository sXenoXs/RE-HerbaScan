# System Testing Plan — HerbaScan v0.9.3

**Testing Type:** Functional — System  
**Scope:** End-to-end user flows through the full running app on a real Android device  
**Date:** March 7, 2026  
**Version:** v0.9.3

---

## Overview

System tests validate complete user journeys from first tap to final result, exercising the entire stack: Flutter UI → Providers → Services → SQLite / Supabase / Railway. Tests are performed on a physical Android device (Infinix X6827, Android 13, API 33) running a debug or release APK. Each scenario is driven manually or via Flutter integration test harness.

## Notes

- System tests are executed manually on a physical Android device unless an automated integration test harness is set up.
- Device: Infinix X6827, Android 13 (API 33), connected via USB for log monitoring.
- All cloud-dependent tests require an active internet connection and valid Supabase/Railway credentials.
- Cleanup test data (uploaded scans, test accounts) after each run.
